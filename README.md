# 🏛️ 남양주시 스마트 조직도 및 직원 연락처 웹 애플리케이션

> **"누가 어떤 부서에서 어떤 업무를 담당하는지, 그리고 어떻게 바로 연락할 수 있는지를 3번 이내의 클릭과 초성 검색으로 확인하는 스마트 행정 웹앱"**

남양주시 공식 홈페이지 조직도(UI·정보구조 기준)와 「남양주시 직위표(2026-9-11).pdf」(조직·직위·성명·내선번호 원본 기준)를 기반으로 구축된 **현대적인 반응형 스마트 조직도 웹 애플리케이션**입니다.

---

## ✨ 주요 기능

1. **계층형 조직도 탐색**:
   - **🏛️ 본청과 제2청사**: 시장, 부시장, 정책보좌관, 비서실, 시장 직속 5관(시민시장, 시민안전, 청년, 홍보, 감사) 및 1실 7국 1추진단(50개 과).
   - **🏥 직속기관 및 사업소**: 남양주·풍양·동부 3개 보건소, 농업기술센터, 상하수도·도로관리·공원녹지·도서관 4개 사업소.
   - **🏡 행정복지센터 (8대 권역)**: 전국 최초 책임읍면동제 적용(와부조안, 진접오남, 화도수동, 진건퇴계원, 호평평내, 다산, 별내, 금곡양정) 거점 읍·동에 과장급(생활자치과, 복지지원과, 도시건축과) 전진배치 구조 반영.
   - **⚖️ 남양주시의회**: 의회사무국장, 4대 상임위 전문위원 및 사무국 6개 팀 연락처.
2. **실시간 초성 및 통합 검색**:
   - 한글 초성 검색 완벽 지원 (예: `ㅎㅁ` ➡️ 화물팀/자동차관리과, `ㅊㅎㄷ` ➡️ 최현덕 시장).
   - 부서명(100점), 팀명(90점), 직원성명(80점), 직위(80점), 주요업무(50점), 내선번호 일치 가중치 검색 및 하이라이트.
3. **부서 상세정보 & 원클릭 전화걸기**:
   - 부서장(과장) 정보, 직급, 내선번호, 대표전화 바로연결 (`tel:`).
   - 소속 팀 및 팀장 카드 리스트, 팀별 전화 연결.
   - 주요 담당 업무 요약 (3~5개 항목).
4. **즐겨찾기 & 최근 본 부서**:
   - 별표(⭐) 클릭으로 즐겨찾기 저장 (`localStorage: nyj-org-favorites`).
   - 최근 조회 부서 최대 10개 자동 기록 (`localStorage: nyj-org-recent`).
5. **다크모드 (Dark Theme)**:
   - 시스템 OS 테마 자동 감지 및 원클릭 수동 전환 (`localStorage: nyj-theme`).
6. **모바일 최적화 (Mobile First)**:
   - 768px 미만 모바일 환경에서 복잡한 트리를 **터치 친화적 아코디언(Accordion)**으로 자동 변환 (최소 터치 영역 44px 준수).
7. **PDF 직위표 자동 파싱 & 갱신**:
   - `pdfParser.js`를 통해 새로운 PDF 직위표 파일 드롭 시 텍스트 좌표 분석 및 정규화 지원.

## 🚀 로컬 실행 방법

이 프로젝트는 별도의 Node.js 빌드 과정 없이 순수 Vanilla Web 기술로 제작되었으므로, 정적 웹 서버만으로 즉시 실행할 수 있습니다.

### 방법 1. 파이썬 웹 서버 (권장)
```bash
# 조직도 프로젝트 폴더로 이동한 후 실행
python -m http.server 8085
```
실행 후 웹 브라우저에서 `http://localhost:8085` 또는 `http://localhost:8085/index.html` 로 접속합니다.

### 방법 2. VS Code Live Server
VS Code에서 `index.html`을 우클릭하고 **"Open with Live Server"**를 클릭합니다.

## 🛠️ 유지관리 및 데이터 수정 가이드

### 1. 인사이동에 따른 PDF 직위표 갱신
1. 웹앱 상단 우측의 **[📄 직위표 갱신]** 버튼을 클릭합니다.
2. 새로 배포된 인사 직위표 PDF 파일(예: `직위표(2027-01-01).pdf`)을 선택하면 `pdfParser.js`가 텍스트 좌표를 추출하여 검증합니다.
3. 또는 `scratch/build_org_json.py` 스크립트를 사용하여 일괄 변환 후 `data/organization.json`을 갱신합니다.

### 2. 전화번호 및 부서 공지 수동 보정 (`data/manual-overrides.json`)
PDF 직위표 외에 특별한 안내 문구나 추가 전화번호를 기재하려면 `manual-overrides.json`을 수정합니다:
```json
{
  "vehicle-management": {
    "notice": "자동차등록 관련 종합민원은 남양주시 제2청사 1층으로 방문 바랍니다.",
    "summary": [
      "자동차·이륜차 종합 등록 행정",
      "화물자동차 운송사업 인허가 및 지도단속"
    ]
  }
}
```

### 3. 부서 주요 업무 수정 (`data/department-tasks.json`)
각 과별 주요 담당 업무 목록을 추가하거나 변경하려면 `data/department-tasks.json`의 해당 부서 ID 배열에 항목을 추가합니다.

## 🌐 무료 배포 가이드 (GitHub Pages / Vercel / Netlify)

### GitHub Pages 배포:
1. 저장소에 현재 폴더의 파일들을 커밋 및 푸시합니다.
2. GitHub 저장소의 `Settings` > `Pages` 메뉴로 이동합니다.
3. `Branch`를 `main` (또는 `master`), 폴더를 `/ (root)`로 설정하고 `Save`를 누르면 즉시 웹사이트 URL이 생성됩니다.
